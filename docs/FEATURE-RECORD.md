## Publishing a verified feature

1. Inspect the current source and run the action in the actual supported build.
2. Record platform, build, source path/commit, successful test steps, and any limits here.
3. Capture the actual application. Follow `ASSET-RECORD.md` and `RECORDING-GUIDE.md`.
4. Add the authentic capture/video and approved feature copy to `src/content/product.json` using the types in `src/lib/product.ts`.
5. `npm run verify:content` verifies file references and evidence fields. It does not independently authenticate screenshots or prove feature correctness.
6. Run the site checks, inspect the real screenshots at mobile/desktop sizes, and run `npm run verify:launch` before publishing.

The website renders detailed feature sections only when the feature has verification evidence and a referenced authentic screenshot. The public bundle receives presentation fields rather than internal implementation evidence.
